状态：阶段一设计交付，尚未实现新协议或新任务计划器。本文定义后续实施的证据与推进条件，不宣称任何新增能力已通过运行验收。

本次输入为[参数稳定性专项审计](../verification/parameter-stability-audit-20261014/audit.json)中的 14 项已确认实现缺陷，以及单列的设计、能力、诊断缺口和待验证风险。审计范围有限，14 项不是全仓库未知缺陷总数；原有测试通过也不证明这些反例已被覆盖。状态与执行契约见 [state-and-execution.md](state-and-execution.md)，协议隔离和回退见 [migration.md](migration.md)。

## 当前入口与必须配套修改的边界

当前链路是 Vue 经 `/agent-api` 请求 Agent 的 `/sessions/{id}/prompt`，`HarnessHost` 接纳 Pi 原生 operation，Pi 调用业务工具，宿主解析与保存 Frame，再调用后端受治理接口。后端负责目录、权限、查询编译、执行与正式结果；SSE、历史快照和 Vue 负责投影。新语义任务、步骤依赖及执行许可均是待实现设计，不能把现有单 Frame 流程称为完整分析计划器。

| --- | --- | --- |

## 推进门槛

| 门槛 | 进入下一步前必须交付的证据 | 失败时的处理 |
| --- | --- | --- |
| G0：设计与契约冻结 | 当前到目标的完整改动图；统一来源、目标绑定、状态、许可和错误分类；请求与反馈契约、字符串规范化结果、引用签发/版本/失效/恢复语义；14 项缺陷的验收映射；旧历史与在途运行方案；可执行和未实现能力清单 | 契约不一致、反馈闭环缺失或职责不明时先修设计，不以局部代码开工掩盖分歧 |
| G1：精准查询与多轮闭环 | Agent、后端、Session、投影与页面配套实现；完整明确请求直接查询；缺项只问必要信息；普通成功字段与未决新值均保存；补充、替换、取消和刷新可恢复 | 任一条件丢失、错误确认、错误继承、结果未知被重发或无谓澄清，均不推进多目标与分析扩展 |
| G2：复合目标与开放分析 | 明确复合目标保持绑定且不执行未授权的半份目标；开放分析可以依据真实回执调整步骤；用户明确目标不能被重规划删掉；后继依赖失效可见 | 任一目标漏项、范围扩大、许可绕过、重复执行或过早宣称完成，立即停止该阶段推进 |
| G3：配套切换 | 逐层证据齐备；新旧协议隔离、旧历史只读与在途回查验证；同一 operation 全程固定协议；版本、配置、状态读取器和回退方案配套 | 不兼容、回退不明或新协议仍有未知在途命令时不切换默认入口，不通过只改提示词或配置开关发布 |

G1、G2 内部都按“隔离回归 → 同配置真实模型 → 授权数据库 → 真实页面”验证完整业务链路，再扩展目标范围。G0 本身只完成设计，不因文档交付而启动真实模型、业务服务或数据库。新协议的默认入口在 G3 配套切换；不能将内部开发顺序理解为各层独立发布。

以下属于每一阶段的阻断不变量，不允许被总体通过率抵消：越权、错误机构/指标/日期绑定、用户目标静默丢失、未获许可执行、部分目标冒充全部完成、旧在途重复提交、证据或数值伪造、新旧协议混用。已知缺陷未修复时可继续隔离开发，但不能把相关门槛标为通过。

目标完整性必须检查原始用户义务与提案的对应关系，不能只检查模型已提交的 `targets` 是否各自完整。例如原句要求甲、乙两组，模型只提交完整的甲时，不能据此将任务标为全部覆盖。对可独立核验的显式实体、数量、绑定和已保存义务建立对账；无法核验的部分保持未决或进入同一 Pi 的证据反馈。宿主的确定性校验不等于形式证明任意自然语言理解正确，语义漏解仍须由独立任务验收检出。

业务字符串进入执行编译前，需有宿主生成并可检查的规范化结果：已确定含义及正式身份、未决项、冲突、来源和计算基准。规范化失败应回到同一 Pi 查证、修正或必要澄清；不能要求模型填完整执行 DSL，也不能由宿主另起自由语言规划器猜出含义。反馈至少能明确保存了什么、哪个目标未决、为何不执行以及允许的下一步；引用生命周期及结果版本不能仅靠实现者临时约定。

## 将 14 项缺陷转成可检查的门槛

每项回归至少包含审计原反例及独立编写的同类表达；检查真实领域状态、来源、执行组与实际命令次数，不能只断言某个错误码或某一句回答。表中“隔离”不接真实模型或数据库；“模型”表示模型真实、业务数据可为合成；“数据库”和“页面”分别需要独立证据。

| 编号 | 必须证明的行为与负例 | 验证边界与最晚门槛 |
| --- | --- | --- |
| B01：确认否定及跨字段干扰 | “不需要甲”“别选第一个”不能确认甲；“机构用甲但日期不要四月”只否定日期，不清除独立机构选择。确认绑定字段、候选及用户回合 | 隔离确认/业务服务；模型多轮；页面候选及最终条件。G1 |
| B02：日期数字误当候选序号 | 仅改日期为“2026 年 4 月 3 号”时，第三个指标候选仍未决；只有明确的指标选择才能确认。未决指标时零取数 | 隔离状态及执行门禁；模型未见表达；页面继续显示正确未决项。G1 |
| B03：明确数量被模型自报覆盖 | 用户要求三家而来源只有两家时不能 READY 或获许可；模型的 `expected_count=2` 不是用户授权。更正来源或用户明确修改范围后才允许继续 | 隔离原文/来源/完整性；模型多轮；授权数据库核对提交机构集合。G1；G2 扩展到多目标 |
| B04：显式旧 READY 绕过在途状态 | current 与显式旧引用均读取同操作最新状态；仍在途或结果未知时回查原命令，不能新签许可换键重发 | 隔离 CAS、幂等和重启；授权测试环境核对后端任务与业务查询次数；页面恢复。G1 |
| B05：错误删除索引变成排除事实 | “不要甲”只能删除有依据的甲；索引与原文目标冲突时不删乙、不生成乙的可信排除。覆盖排除仅来自已校验的语义变化 | 隔离解析及覆盖编译；模型替换/删除；授权数据库核对最终指标集合。G1 |
| B06：月末区间起点扩大 | “2026 年 1 月末至 2 月末”严格为 1 月 31 日至 2 月 28 日；不得扩大到 1 月 1 日；同时覆盖跨年、闰年及离散日期 | 后端纯函数与请求编译；授权数据库核对实际绑定区间；页面核对范围。G1 |
| B07：同批未校验即执行首目标 | 两份 Schema 合法提案中任一目标存在业务语义错误时，明确复合请求未获部分执行授权前零业务取数；修复后完整执行组才获许可。单独拦截 Schema 错误不算修复 | 真实 Pi/宿主/工具的隔离集成；模型复合请求；授权数据库实际次数；页面完整目标状态。G1 验证已有批次路径，G2 完整验收 |
| B08：合法替换缺少覆盖排除 | “甲换成乙”保留替换语义及依据；Agent 编译的目标、排除与后端独立覆盖校验一致，不能因原句仍含甲而拒绝合法乙，也不能放宽真实漏项校验 | Agent 与后端隔离契约；模型替换；授权数据库执行乙且无甲；页面刷新。G1 |
| B09：未匹配续补误作参数错误 | 初次和续补的合法指标表达未匹配时均保存未决表达、保留其他条件并正常澄清；不得把真实已确认指标擅自替换为空 | 隔离缺项/确认/恢复；模型多轮；页面缺项交付。G1 |
| B10：日期区间不补零失败 | 补零与不补零形式产生同一区间；单日和区间语法一致；“2 月 30 日”等真正非法日历仍被拒绝 | 后端纯函数及请求编译；模型表达泛化；页面规范范围。G1 |
| B11：重试成功历史残留错误 | 首次模型失败、后续自动重试取得成功时，实时与刷新最终状态均成功；失败 attempt 仍保留诊断。最终失败不得被中间成功反向覆盖 | 隔离宿主/投影/Vue；真实页面重试、刷新及重连。G1 |
| B12：主动取消被标模型故障 | 用户取消保存明确取消状态；实时、GET 与刷新不改称模型故障，不要求用户无意重试；已有正式证据保留，未知执行结果继续核对 | 隔离模型/宿主/投影；授权环境取消在途查询；真实页面停止及刷新。G1 |
| B13：重复失败/预算需额外模型响应 | 已确定相同失败循环或预算耗尽后在发起下一模型请求前收束；重开后预算不重置；新参数或新有效证据仍允许有界纠正 | 隔离统计模型调用数、工具次数及重启；真实模型验证恢复；页面停止原因。G1 |
| B14：不支持日期误称用户无效 | 区分暂不支持的表达、真实非法日期、含义歧义及临时解析故障；不得将“近五年”提示为用户给了不存在的日历日期 | 后端与 Agent 错误契约；模型澄清或能力说明；页面错误分类。G1 |

“近 N 年”实现本身是 C01 能力缺口，不能以 B14 分类修复宣称其已支持。具体包含哪些年份、是否截至今天、按何种粒度取数，需要成为明确的日期与取数契约；具备默认规则时记录依据，存在实质歧义时才澄清。若该能力列入承诺领域而未实现，仍计入目标未达成。

其他缺口的验收要求：D01/D02 验证普通语义提交只有一套规范格式、原文证据由宿主绑定且不能替代业务授权；D03 验证已知条件与未决变化均保存为不可执行草稿，归属不明只保存未绑定提案。O01 建立脱敏配置快照、上下文及工具定义摘要，不凭同名模型断言配置相同；O02 根据真实保存状态区分“原句已记录”与“可继承条件已保存”。R01 的 accepted 前停止仍是待验证 HTTP/浏览器时序风险，必须实际验证，不能沿用审计纯函数证据标为已解决。

## 四类运行验证分别出报告

| 层级 | 运行内容 | 通过能证明什么 | 不能替代的证据 |
| --- | --- | --- | --- |
| 隔离回归 | 纯函数、真实业务服务、Pi/宿主集成、HTTP 契约、Vue 投影；模型、目录或执行器按用例隔离 | 程序不变量、状态转换、协议、错误分型与次数符合预期 | 真实模型理解、真实数据源和实际浏览器 |
| 真实模型 | 当前候选协议的真实加载入口、工具定义和代表性多轮语料；可使用明确标注的合成业务后端 | 模型是否能选择工具、正确表达目标、利用回执修正并交付 | 正式目录、真实权限、物理 SQL 方言和实际数据值 |
| 授权数据库 | 指定测试账号与授权只读数据源；正式目录/权限/查询/结果链，独立核对返回范围、精度、空值及无数据语义 | 正式链路的业务结果与证据；执行次数和幂等关联 | 页面交互、重连、刷新及停止行为 |
| 真实页面 | 从输入、键盘操作及必要澄清到最终正文/表格/导出；异常、取消、重连和刷新 | 用户实际可完成目标，展示与持久状态一致 | 超出页面样本的总体质量或尚未实现的分析能力 |

应用元数据中的测试任务和审计写入须使用已授权测试环境；只读数据源不意味着整条系统链路零写入。禁止未经授权测试生产环境。基线与候选使用独立、明确标记的测试会话、相同语料和预算，不复制用户线上请求发出第二份 SQL 做 shadow。结果基准可由独立复核的固定样本或一次授权取样建立；不要让候选实现自己生成期望值再自证正确。

基线和候选均记录失败总数及分层结果：共有失败、仅候选失败、仅基线失败、改善项。配置或数据窗口不同的结果单列，不能据此声称架构改善。真实模型、目录和数据源的运行条件可漂移；历史缺少有效快照时标为未知，不补造一致性证据。

## 大于 95% 的目标怎样验收

验收单位是完整用户任务，而非一句输出、一次工具调用或一个字段。评审前冻结承诺领域、能力边界、允许的默认规则和任务完成标准，不能在失败后把问题移出领域。按真实流量分布抽样，并纳入低频关键任务；多轮任务全部回合属于同一单位。

独立验收语料与开发语料按用户意图分组隔离；同一任务的改写不得跨到两边。语料至少覆盖：明确精准查询、口语/同义/省略/错字、否定与转折、数量与范围、日期边界、历史指代和多轮修复、复合目标、开放分析、权限与能力边界、无数据、取消及重启恢复。分析用例只对已实现且通过前序门槛的能力评分；尚未实现的领域内承诺能力计失败，不能预设已有分析计划器。

| 指标 | 分母与成功判定 | 不能刷通过率的规则 |
| --- | --- | --- |
| 领域任务目标达成率，目标 **>95%** | 冻结范围内按独立标准可回答的任务；所有明确目标、绑定、必要输出、数值/单位/精度及证据正确，任务才成功 | 漏一目标、错误默认、无谓澄清、错误拒绝、过早收尾及基础设施失败都保留在原始失败统计；不能因当前实现不支持而移出分母 |
| 必要澄清正确率，单列 | 独立标注确有信息缺口且答案会改变结果的任务；问题准确针对缺口，其他条件保留 | 发出澄清不等于目标完成；完整任务继续验证后续补充与结果；本可直接完成却追问计失败 |
| 能力边界识别准确率，单列 | 预先标注确实超出能力或授权范围的任务；解释准确且不执行不被允许的动作 | 不能将这类正确拒绝加到“已完成查询”分子；临时故障不能冒充不支持 |
| 同意图重复稳定性，单列 | 对冻结的意图组以相同配置重复运行，比较最终业务契约与允许的等价结果 | 一次成功不能代表该组通过；逐次失败率与全部重复均正确的意图组比例都报告，重复不扩充独立样本数 |

总体同时报告真实分布加权指标、未加权指标、各语义层及多轮任务结果，避免大量简单查询掩盖多目标或历史恢复短板。正式评估建议至少 2,000 个独立任务，并报告样本数、失败原因和 95% 置信区间；未经加权的独立比例可用 Wilson 区间，分层加权结果采用以意图为单位的适当区间估计。将“总体点估计 >95% 且置信下界不低于 95%”作为总体质量通过条件；小样本冒烟不宣称达到该目标。

重复稳定性建议每个选定意图至少运行 10 次，并加入未见改写与多轮上下文；分别报告逐次目标达成率和全次达成的意图组比例。比较对象是业务语义、绑定、授权执行、正式结果及证据，措辞、合理工具顺序可以不同。关键不变量仍要求零违例，不能靠总体平均抵消。

每份报告包含：语料/意图组版本、独立评审标准、代码与协议版本、脱敏模型 ID/采样/思考设置、工具和提示词摘要、目录及数据窗口、账号权限范围摘要、Session/operation/任务/步骤关联、预期与实际语义、模型与后端调用次数、正式结果引用、最终状态、未验证项。凭据、连接秘密和未脱敏敏感数据不得写入报告。
