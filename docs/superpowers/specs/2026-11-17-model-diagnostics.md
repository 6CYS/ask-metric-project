# 模型诊断

## 已确认范围

在「智能配置」增加「模型诊断」页签，与模型配置、提示词配置、Skill 管理并列。系统管理员手动检测当前问数实际使用的模型，支持停止，显示检测时间、首次有效输出耗时、总耗时及明确的失败原因。结果只代表对应时刻的一次轻量流式请求，不作为持续健康状态或业务正确性结论。

## 实现边界

- 复用 Agent 的已生效配置、数据库配置快照、模型鉴权、流式客户端和错误分类；不使用页面草稿、不允许指定任意地址或密钥。
- 固定短诊断提示，不携带业务数据、不执行指标查询、不写入聊天会话，不执行工具。
- 每次手动检测只发送一次模型请求，不自动重试；输出预算最多 512 token、总检测预算 60 秒，保留当前配置中的首响应及流空闲时限。
- 单个 Agent 实例同时最多一个检测，开始后至少间隔 10 秒才允许再次启动。该限制不是跨实例或网关的全局 QPM 保证。
- 首次有效输出包含实际思考、正文或工具调用增量，与现有模型超时口径一致；完成必须收到成功终态及正文，不把断流、空回复或截断视为成功。
- 页面离开或点击停止会取消本次 HTTP 等待并向模型传递取消信号；不声称模型网关内部推理一定已停止。
- 使用当前登录鉴权，服务端限制 SYSTEM_ADMIN；不要求写配置权限。检测详情可展示本次模型回复正文、HTTP 状态及模型/网关错误内容，凭据与配置地址先脱敏，内容按纯文本显示并设置长度上限；不展示思考内容，不把返回正文写入日志。
- 第一版保留本页当前检测结果，不新增历史诊断数据库或自动巡检。历史问数失败仍从现有记录查看。

## 方案选择

沿用现有智能配置入口增加独立页签，清楚区分「测试配置草稿」和「检测已生效模型」。避免混用现有后端非流式连接测试；复用 Agent 模型客户端即可验证连接与输出，不引入业务查询或完整问数流程。

## 验证

隔离边界覆盖权限、配置来源、成功、限流、超时、断流、取消、重复点击和敏感信息；桌面浏览器核对真实模型检测及可控故障交互。内网网关行为需现场验证，不把隔离测试称为内网验收。

## 本次返回内容展示

按用户要求，在已有诊断详情中直接查看本次返回。沿用一次请求、无业务数据、无自动重试的范围；不增加真实业务故障历史或监控平台。

SSE result 兼容增加可选 `model_response`，字段为 `http_status: number|null`、`content: string`（模型正文，可为部分输出）、`error: string`（网关响应或客户端错误）、`error_source: http|client|null`、`truncated: boolean`。不把 SDK 生成的连接错误冒称网关原始返回；没有收到正文时明确显示未收到。模型思考不进入正文展示。

正文与错误各最多展示 8192 字符；HTTP 错误读取有上限并服从原取消和总时限。已知配置凭据、敏感字段及配置地址脱敏后再展示。保持文本换行，限制展示区高度，提供复制；前端兼容旧服务端没有该字段的结果。成功回复、429 JSON、非 JSON 错误、部分输出后失败、无响应、脱敏与超长内容均纳入回归。
