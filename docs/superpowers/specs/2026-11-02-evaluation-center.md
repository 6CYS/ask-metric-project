# 测评中心第一版

以独立一级菜单提供问题集、多轮批量执行、结果详情、人工复核和批次对比。复用现有 Vue 组件、认证和 Agent V3 会话接口，不迁移另一套问数引擎，不新增依赖，不切换全局模型。

问题集支持编辑和 JSON 导入导出；一组代表连续会话，组内问题有稳定 ID、问题和人工期望说明。没有经过业务确认的参考答案不自动判为标准答案。运行冻结问题集版本，每次重跑生成全新批次和会话。运行完成只代表执行结束，业务是否通过由人工复核记录，二者独立。

服务端同一时间只运行一个测评批次，组内串行，组间新建会话；失败后跳过依赖该轮的后续追问，继续下一组。停止需调用现有取消接口，不只断开 SSE。令牌只保存在运行内存，身份过期停止批次。进程重启将未完成批次记为中断，不自动重跑或重放提问。结果详情复用会话当前授权投影，不能绕过撤权后的历史访问控制。

结果保留会话、请求、用户条目身份、终止状态和实际耗时。正文、图表、查询依据从正式会话快照读取；不把流式预览当作最终结果。版本对比按冻结题目 ID 对齐，明确问题集、模型和数据条件差异；数据条件为人工登记，不能冒充数据库快照。

桌面验收；不写演示业务数据，不修改现有模型和数据源配置。源码修改限测评模块及必要注册入口。
