# 回答流式交付

目标：在现有问数逻辑、事实校验及最终快照之上，让已生成且通过核验的正文及时展示，保持图表、停止和刷新恢复一致。不新增模型调用、查询路由或人为打字延时。

## 实现边界

1. 报告预览复用正式报告的权限、来源、引用值和单位核验。只预览完整段落或已结束的同级列表项，不执行日期覆盖查询、图表装配或整体交付；最终报告仍按原契约生成。
2. Agent 只观察明确提交的 `analysis_answer.body`，在空行或下一同级列表项开始时交付完整前缀，保持续行、子列表、代码与未闭合引用完整。普通 assistant 文本可能仍是规划，不直接展示；自然正文兼容路径继续通过正式回执交付。每个观察流最多一个预览请求在途，后续合并为最新前缀；取消、重试、工具调用及终态使旧预览失效。
3. POST 与重连 GET 共用投影器，观察不启动另一轮问数。临时正文不持久化为业务答案，刷新从原生会话和活动执行恢复；正式快照具有最终权威。
4. 前端按浏览器帧合并累计正文，保持同一 Markdown 容器。只有靠近底部时跟随，上翻后不抢滚动。终态、切会话及卸载清理帧队列。

## 增量与恢复收敛

- 已核验前缀仅限单条观察流、同一操作与模型尝试复用；使用实际来源、焦点、计算和绑定作为复用条件。全文仍用于准备来源，新完整段落单独送后端校验；单换行追加的列表项核验累计正文，保留同段引用上下文和原始排版。来源权限与元数据继续逐次检查，不缓存放行。
- 明确的正文错误不因继续追加独立段落反复调用预览；同段列表补齐依据、正文改写或新尝试可重新核验。暂时故障保留已核验前文，只在下一完整片段到达时再尝试，连续两次失败停止本次预览。正式交付与原业务预算不变。
- 历史复用回答的标题先于正文引用到达时，预览标记为等待依据，后续完整前缀仍继续核验；未知引用继续拒绝。正式回答仍必须明确历史来源焦点，不把标题单独放行。
- 无目标覆盖检查的预览不读取无用的历史消息；有目标检查及正式报告仍按原契约读取。引用值由正式来源渲染，但原有普通正文的 `|cite` 不核对相邻手写数字，不能将引用核验表述为所有自然语言数值均已核验；本次不扩大正文语义校验。
- 快照明确当前有效的正文尝试。前端仅保留同一操作、同一尝试的预览；取消、重试、截断及来源失效撤回旧内容。取消或终态之后的缓冲事件不再交付。
- 停止提示统一从原生消息和 operation 终态投影，按原生条目关联到对应轮次，覆盖工具执行中取消及取消后继续追问的历史恢复，不另存一份终态。
- 最终报告开始执行时取消尚未完成的预览，不为了首段展示延迟正式结果。单段短回答可能直接出现正式结果；长时间模型规划与查询不属于此项提速承诺。

## 段落核验的目录读取范围

- 预览按全部授权来源中的指标编码读取当前口径，同时读取主题基础映射的必要候选；保留同名和别名竞争者，由原有绑定规则判定歧义。不同预览请求仍重新检查来源权限及元数据，不使用跨请求缓存放行。
- 同一次报告请求中的计算凭据复核复用本次语义对象，不再为每个计算重新读取目录；独立计算入口保持原有复核方式。
- 最终报告仍完整读取一次目录，保留未查询的规划缺口和正式指标名称转换行为。目录读取只加载业务需要的字段，不创建完整 ORM 实体。
- 验证覆盖新旧数据库字段兼容、同秒口径变更、别名冲突、基础指标停用、配置变更、权限撤销及多个计算凭据；真实目录逐项比对描述与绑定，页面核对实际分段事件及最终回答。

## 验证与完成条件

- 报告：合法段落通过，非法引用、数字、权限失败拒绝；预览不写业务状态，正式覆盖检查不变。
- 投影：分片引用/表格/代码块不提前展示，慢请求合并，重试/取消后无旧内容，原始引用不发送到浏览器。
- 界面：正文增量、正式替换、图表、停止、上翻与刷新恢复；实际桌面使用已有业务数据及模型验证。
- 执行相关类型、lint、测试和构建，检查最终 diff，保留原有配置及无关改动。

本轮不承诺模型总耗时下降；记录实际首段与总耗时。预览只在段落核验通过后可见，不能把内部引用或未经核验的数字直接逐 token 展示。

真实联调发现普通文本可能在后续调用工具前已经产生多段规划；数字校验不能区分这种通道。实现据此收敛到已有报告工具的正文参数，流式开启时明确要求模型用此入口交付；保留关闭开关后的原有输出契约。不按“让我”等词语增加过滤规则。
