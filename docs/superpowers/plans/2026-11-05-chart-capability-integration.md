# 图表能力本地融合

## 已确认目标

将 hismart 三件套中已使用的图表优点吸收到 Ask Metric；整合后的实现由 Ask Metric 自己运行。参考 text2sql-web 的 develop@7f356fb11d6b2699b1b4a8a649f888d96d6d383c 已提交源码，参考仓库只读。延续本聊天已授权的多图、随文展示、图形适用性与实际桌面验证，不提交或推送。

## 实施边界

1. 本地 option 层吸收桌面布局、分类窗口、图例和标签避让，以及按数据结构判断图形可用性的做法。保留已核验的来源、单位、原始数值及 display。百分比差额使用正式 comparison_role 决定“个百分点”。
2. 当前前端组件加入统一图形选择和放大交互，复用项目 Reka UI 控件；保持 ECharts 实例、图例选择和缩放状态。沿用参考的推荐、可用、谨慎、禁用区分；机构分类可以切折线或面积，但注明不代表时间趋势。已核实组成沿用原饼图；服务端标明为机构比较的可加数值可切饼图，明确限定为所选机构合计占比。不为图形补零或补造数据。
3. 现有 answer_delta 增可选 charts 字段，按已核验正文前缀发布图集。正文与图集原子更新，旧协议兼容；reset、重试、跨回合及最终交付清理预览。图表使用稳定身份，在安全 Markdown 块之后插入。
4. 服务端预览继续鉴权并检查来源和数值，只增已有 body_evidence 返回，不建新服务、不调用三件套接口、不增加取数。新字段不可用时保留原文字流。seriesChart 额外返回可选 category_kind，直接复用已有机构、指标、时序判断；旧记录缺省兼容，不凭标签猜分类。

## 职责与校验

服务端负责权限、来源、机构、日期、正式口径与计算；前端负责图形适用性、渲染结构与交互。合并相同职责，不引入通用审核层。保留 formatter 转义，不执行模型函数文本。参考项目的服务、主题状态、国际化与导出依赖按当前需要取舍，不整体复制。
