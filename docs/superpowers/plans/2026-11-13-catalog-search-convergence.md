# 目录检索收敛与过程展示修复计划

**目标：** 正常无匹配能够清楚交付，已知无效检索不继续冒充进展，保留有效补查和多指标查询。

**实现：** 沿用目录工具回执、现有问数重复控制和聊天过程组件；不降低全局调查预算，不增加词语白名单或通用审核层。

**范围：** `agent-service/src/inquiry/queryTools.ts`、`runtime.ts`、`tools/turnContract.ts`、相关回归；`frontend-vue` 的过程组件、摘要转换与相关回归。保留工作区原有变更；提交仅包含本任务内容，不部署。

- [x] 核对可获取的真实会话回执，区分换词、有效分页、耗尽分页与复用。
- [x] 补充能复现耗尽分页误算进展的回归，修正整批无新增信息标记；纯复用与混合批的实际新结果分别处理。
- [x] 增加向后兼容的目录摘要 `search_summary`，说明候选数、是否有后续页、整批复用或耗尽。

- [x] 默认收起执行过程，合并连续完成的目录步骤，保留异常及原始调试记录。
- [x] 运行相关回归、类型检查、构建，检查实际桌面流程及最终差异；如实记录新关键词探索仍有耗时波动。

## 验证边界

覆盖首次空匹配、有效下一页、耗尽后改变页码、改变页大小、混合新旧检索、多指标、旧回执与新轮次。权限和服务异常保留既有语义。真实会话和真实模型结果与隔离单元测试分别报告；未取得实测证据不声明耗时改善幅度。

## 已核实的根因与修正边界

原会话进行了 15 次目录检索，全部是第一页；主要是变换表达、增大页大小、重复携带已查空关键词，最后达到调查预算才交付。原模型累计调用耗时约 51.1 秒，整轮约 71.4 秒。

真实变体验证中，同组已复用检索被拒绝后仍继续尝试。交付工具未明确列出“实际检索后无适用指标”这一正常终态，已与运行时允许的交付路径保持一致；不得将目录查空当作服务失败。

仅拒绝重复请求不能保证模型立即收尾，但不能因此将局部重复扩大为整轮停止。2026-11-16 删除全复用共用计数及其整轮关闭条件，恢复按实际请求局部限制；已有候选取数、其他目标和有效分页仍开放。已取得正式查询结果（含空结果）继续经过正式核验与必要的部分结果恢复。

词法零命中不等于语义推荐完整。跨页大小复用仅采用已关闭语义推荐或没有推荐数据的兼容回执；语义推荐暂时故障和扩大页大小可能获得更多建议时仍允许有界恢复或补查。保留全局预算与正式证据保护，不新增按词语判断目标的规则。

## 用户确认的边界

历史版本原句与改写接口实测均为 11 步，桌面同句复测为 16 步、约 56 秒；该版本包含现已撤回的整轮关闭条件，不能将这些数字作为当前版本的性能结果。

不采用统一“两次查空即结束”或“两次全复用关闭整轮”的规则。保留结果复用、按请求局部重复限制及过程展示优化；未引入逐指标目标识别层或新的探索预算。
