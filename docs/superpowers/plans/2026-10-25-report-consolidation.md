# 报告校验与纠错收敛实施计划

**目标：** 保留必要的证据校验，减少重复重写和按段裁剪，使合法指标组合都能根据真实结果完成有界交付。

**实现范围：** 沿用 TypeScript Agent 与 Python 后端的现有报告入口、回执和预算；不增加依赖、服务、数据库表或状态机。模型正常正文仍可使用，确定性恢复只引用已验证事实，不根据错误文字猜测数据。

**设计依据：** `docs/superpowers/specs/2026-10-25-report-delivery-design.md`，本次仅实施报告校验、恢复和结束规则；页面超过 100 行的展示、SQL、模型配置及超时调整不在本次范围内。

**执行约束：** 在当前已有联调工作区修改，保留用户未提交配置和文档；实施时未提交推送，后续提交按用户单独授权执行。单元验证使用隔离回执，实际验收使用现有 3309/ads_lake、当前实际生效模型和新建测试会话。

- [x] 在 `analysis_report.py` 对正常和恢复路径先校验来源、引用及依赖；删除按段裁剪恢复，原始结果不随文字错误丢失。
- [x] 复用 `verified_findings.py` 的正式比较身份，删除重复的方向判断，保留有限文字边界且不追加句式正则。
