# 指标关系与知识关联

## 目标与范围

在现有指标菜单加入关系图谱和关系维护，保留指标定义、单位、口径及同义词维护。业务知识继续以标题、内容和启用状态为主，相关指标选填；不增加适用场景或通用/指定分类。

不改聊天、SSE、报告预览或事实查询流程，不新增图数据库、RAG 框架或图形依赖。当前并行窗口正在修改指标语义读取；其改动稳定后，仅接入关系模型及目录关系说明，保留其优化。

## 数据契约

- 自定义关系复用 `analysis-semantics.json` 的 `relations`，分类、组成、占比依赖明确区分。旧无类型关系按分类兼容，不能提升为完整组成。
- 占比关系的主指标为结果指标，两个依赖顺序为分子、分母；维护公式依赖不代表当前机构、日期已有可计算数据。
- 既有业务主题关系只读投影，未绑定指标如实标明。带固定核对公式的预置关系不允许通过普通表单改变成员。
- 保存校验正式目录、成员唯一性、依赖循环与类型对应单位；按文件版本检测冲突并原子写入，保留其他配置。
- 知识新增可选 `metric_codes`，空列表不限制正文召回。查询上下文包含正式指标编码时优先召回显式关联知识；指标详情反向查询同一字段。

## 任务

1. 知识契约、关联校验及反向查询；验证旧资料保留、清空关联、并发冲突及检索兼容。
2. 关系模型、维护接口及原配置读取；验证权限、无效成员、循环、单位与旧配置兼容。
3. 指标图谱和详情、关系编辑、知识可选选择器；复用现有导航、表格及弹窗。图谱聚焦当前指标及相邻关系，避免一次绘制上万指标。
4. 目录发现展示显式关系，分类与公式依赖不混入可加总结论；不新增自动归因算法。
5. 定向类型/lint/测试与构建，实际桌面查看图谱、搜索、选择和表单。独立端口验证新接口，避免重启并行窗口正在验证的服务。
