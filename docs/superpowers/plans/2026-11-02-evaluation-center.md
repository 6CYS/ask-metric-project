# 测评中心实施计划

**目标：** 在现有问数链路外增加可实际使用的独立测评中心。

**架构：** Agent 服务新增 evaluation 模块，沿用单实例数据目录保存版本化问题集和批次；通过现有 V3 HTTP 路由执行问数。Vue 新增独立页面和模块组件，复用当前登录身份及同源代理。

**技术栈：** TypeScript、Hono、Vue 3、现有组件和 Vitest，无新增依赖。

**设计说明：** `docs/superpowers/specs/2026-11-02-evaluation-center.md`

## 全局约束

- 当前账号和当前模型配置执行；令牌不落盘，跨账号不可访问。
- 全服务测评并发为一；每批最多 100 轮；不自动重试提问，不篡改正常聊天主流程。
- 问题集更新检查版本；每批冻结问题和期望，重跑不得复用旧答案。
- 执行结果与人工结论分开；来源和正文复用当前授权的会话快照。
- 隔离工作区开发，整合时仅加入本任务文件和入口行，保留其他窗口改动。

## 检查重点

- 同组连续追问的会话身份与条目范围；失败后不能把下一问当作独立成功。
- 取消时 SSE 断开不能代替停止执行；权限失效后不得继续取数。
- 服务重启保留结果并显示中断；详情读取不能触发旧操作恢复。
- 过期编辑、并发创建批次和跨账号结果请求应有明确拒绝。
- 页面刷新、快速切换详情、轮询失败和卸载不造成重复执行或过期数据覆盖。

## 提交前代码评审

本轮评审覆盖新增测评模块与注册入口，未扩展为问数引擎或其他窗口功能的重构。修正范围如下：

- 题集身份生成使用兼容行内 HTTP 的浏览器能力，不依赖 `randomUUID`。
- 完整批次回执统一更新当前选择，使过期详情和单批次请求失效；终态、停止回执和刷新一致。
- 测评适配识别既有 403 权限拒绝回执，停止剩余组，避免将权限拒绝视为普通失败继续执行。
- 取消未确认时保留执行占用，允许当前有效身份再次确认停止；不后台无限重试，也不放行新的重叠批次。
- 接纳后的轮次身份即时持久化，运行态与终态区分；中断后仍通过当前权限读取已保存内容，不自动重放。

新增回归分别验证缺失浏览器 API、迟到响应、权限终态、停止重试和中断身份恢复。最终提交快照检查：Agent 63 个测试文件、1,174 项通过，前端 24 个测试文件、202 项通过；两端类型检查、测评文件 lint、格式检查及构建通过。首轮共享工作区检查曾遇到同期 SQL 排版未完成用例；该功能随后由其他窗口独立提交，前端已在更新后的基线上复验。验证快照只包含已提交基线与本轮明确文件，没有夹带其他未提交改动。
