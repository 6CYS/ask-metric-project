范围：沿用现有 TypeScript 工具与 Python 查询、报告模块；不新增审核层、数据库结构、依赖或页面。保留权限、资源归属、正式指标、实际期间、原始事实、单位与计算保护。工作区已有修改逐文件保留，基线存于 `/tmp/ask-metric-chain-repair-20261111/before`。
