# 问数执行 SQL 查看实施计划

**目标：** 在已确认的聊天页原型上增加只读 SQL 查看，供核验实际取数条件与记录。

**实现：** 复用 QueryRun、不可变结果快照及现有鉴权。回答下方提供入口，右侧抽屉按查询切换；详情仅点击时读取，不增加模型调用或重跑业务查询。SQL 和绑定参数分别呈现，结果页来自对应快照。

**范围：** Vue / TypeScript、FastAPI / Python；不新增依赖，不修改数据库结构，不改变问数执行与回答逻辑。按用户要求提交推送已完成代码和项目文档；本机配置及其他窗口仍在开发的内容保留。
