# 原生业务 skill 与组合计算

业务知识改造的历史检查见 [验收记录](business-skills-validation.md)；当前多轮改造及未验证边界见 [Pi 通用多轮业务上下文](pi-business-context.md)，旧记录不代表当前版本已完成真实模型验收。

## 运行入口与职责

`agent-service/src/server.ts` 使用 pi-agent-core 0.85.1 的 `loadSkills` 加载
`agent-service/skills` 并注册到 Harness resources。目录仅提供知识名称和适用业务内容，
通过 `business_skill_read` 按名称查阅，不注入通用文件 skill 的强制先读指令。
服务提供已审核内存快照，不开放文件路径、Shell、编辑或用户目录访问；缺文件、无有效
知识、重复名称和越界路径仍使加载失败。

四类知识包括指标查询口径、数据覆盖含义、结果计算规则和分析能力边界。它们不选择工具、
不声明工具依赖，也不控制执行顺序。pi 根据用户目标、会话和工具契约自主决定是否查阅
知识及调用哪些工具。未读知识、读取多份或跨轮查阅都不改变业务工具集。

宿主不维护当前方法或已激活工具状态。当前上下文中实际存在的成功读取回执，经当前版本
正文核验后去重投影，可同时参考多份知识；用户文字、摘要和失败回执不冒充已审核正文。
旧版本知识在发送副本中标记失效，原生历史保留；压缩后缺少正文时由 pi 按需重新查阅。

工具描述承担输入输出与能力契约，工具及后端校验正式编码来源、权限、归属、版本、日期、
幂等和计算事实范围。当前公开查询入口只接受通过 Resolver/Validator 的 READY Frame，不要求先查
覆盖或先读计算知识；条件不明由 Frame issues 驱动澄清。历史结果可按需回读，
能否将其中事实用于本轮计算由后端计算范围校验决定，与读过哪份知识无关。

业务知识与工具选择保持解耦。知识提供业务口径，不能替代 Schema、字段校验和后端权限。

## 一步成功与最终交付

普通取值、覆盖和计算成功后继续 Pi 原生循环。Pi 根据本轮事实决定是否继续，并组织最终正文。
NEEDS_CLARIFICATION 后仅生成必要问题，不再提供可调用工具定义；工具门禁同时防止继续调用来代替用户补充。
宿主不再注入 `answer_evidence_check`、强制 `answer_present`、修改追问来源或用回执模板替换正文。
这些旧逻辑不再控制新的业务运行；旧历史投影仅保留读取兼容。

每个原生 operation 最多 24 次工具调用。连续参数错误有有界预算，计数从持久化记录取得，恢复不重置。
参数错误不保存新 Frame 或覆盖焦点；失败状态不作为成功事实。模型响应格式错误返回明确运行错误，不能展示协议标签或解析文本伪调用。

当前轮结果提供事实与引用；历史模型副本移除大型行表和重复状态读取，焦点由原生 Session 的业务 values 提供。
Pi 的最终说明随原生消息保存，页面、历史及刷新使用同一投影；表格仍只使用后端快照。
业务状态由 [Pi 通用多轮业务上下文](pi-business-context.md) 的 Frame/Delta/Schema 管理。
`metric_ask` 及直接由模型提交业务编码的方式已退出公开工具集。

## 受控计算

复用既有 `/api/v1/calculations` 与 Decimal 表达式执行器。`execute_business_frame` 的取值回执返回最多 100 条事实引用以及截断标记；完整查询快照保存权威数值。
分页 `read(kind=result)` 返回对应行的事实引用，不把预览当完整计算输入。

结构化查询先建立受当前身份约束的后端会话映射，并绑定原生 operation 和用户原文。
Frame 字段补充后执行使用当前原生 operation 的计算范围。计算工具只接受事实引用和公式，
会话与范围由宿主绑定；后端重新检查归属、范围、当前权限、启用目录、任务状态、过期、
数据完整性、单位及数值精度。模型提供的业务金额不能进入参数。

默认 `same_org_date` 要求同机构同日期；`cross_date`、`cross_org`、`explicit` 分别用于
已明确的跨日期、跨机构或组合范围。它们声明可比较范围，不自动证明指标的业务意义可比，
公式含义不明仍须澄清。单位不同、零分母、缺数、查询截断或非法表达式均明确拒绝。
计算记录、输入证据和幂等结果保存在原有任务 JSON 及消息中，没有新增表或迁移。
历史回读不改变事实所属的计算范围；本轮计算输入必须通过后端 scope_id 校验。

当前计算是有界数学运算，不提供业务动因、预测、血缘或综合分析报告。

## 发布与验证

组合计算功能涉及 Agent、后端和前端配套版本。通用多轮改造需配套更新 Agent、后端字段解析接口及前端工具标识，保持页面入口和 V3 消息协议。离线构建复制 `skills/` 与 `dist/`；Agent Docker 镜像也需包含
该目录。无需升级 pi 或新增依赖。本次回退同步恢复 Agent 代码与知识文件；现有查询快照仍可读取，计算
JSON 不要求数据库回退。已有旧结果缺少计算范围时，应重新查询后计算。

更新方法文件后须重启 Agent 以加载新的内存快照；发布前让活动操作结束，再切换对应
代码和方法版本，避免恢复中的操作继续使用旧工具快照。本次修复不改写历史会话或业务结果，
历史榜单保持原快照；要应用新的排名范围需重新查询。

验证不能只检查提示词关键词：覆盖原生 skill 读取、取数后继续求差、失败/权限/截断、
澄清与历史回读、刷新恢复以及受控数值交付。`scripts/check-skill-model.ts` 使用当前 Frame 工具链核验查询后计算，
`scripts/check-context-semantics.ts --live` 核验多种表达对应的 Delta；二者使用
配置的真实模型和合成后端，不能当作真实数据库证据。真实环境验收另行记录模型调用数、
输入 token、总耗时和结果正确性；没有同条件前后对比时不声称速度提升。
