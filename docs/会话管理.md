# 会话名称与删除

- 双击左侧会话名称或顶部当前会话名称可就地修改，也可使用会话菜单。Enter保存，Esc取消；名称最多255个字符，可以重名，实际操作始终使用会话ID。
- 已创建的会话名称写入Agent原生会话存储，刷新或重新打开后保留，不改写原问题、取数条件和历史回答。尚未发送的草稿先保存在当前浏览器，首次创建正式会话后保存到服务端。
- 左侧“管理”进入批量模式。“全选已加载”只选择当前展示部分，另有“选择全部N个可删除会话”用于明确选择全部历史。分析中、发送中和旧格式只读会话不纳入选择。
- 确认默认显示前3个会话及总数，展开后每页核对10个。删除最多并发4个请求，展示实际完成进度；部分失败保留未删除项，可只重试失败项。删除当前会话后统一切换一次，不逐条加载其他历史。
- 改名失败保留编辑内容；删除期间禁止重复提交。已不存在的会话按删除完成处理。接口仍逐次校验当前身份和资源归属，运行中的会话由服务端拒绝删除。

## 接口与更新

新增 `PATCH /agent-api/sessions/:id`，请求为 `{"title":"会话名称"}`，返回 `session_id` 和规范化后的 `title`。空名称或超长返回400，无权访问或不存在返回404，旧格式只读返回409。

前端与Agent服务需一并更新；后端Python服务和数据库结构无需变更。旧浏览器标题覆盖仍兼容，在该浏览器改名或继续提问时可写入正式会话。回退界面不影响问数正文和证据，已经删除的会话不能通过回退恢复。
