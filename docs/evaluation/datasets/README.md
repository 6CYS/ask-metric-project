# 问数测评集

在「测评中心 → 问题集 → 导入 JSON」逐个选择文件。每个文件最多 100 轮，分批导入时保留组内首问和追问顺序。

- [0618 版本](batches/0618版本/)和 [0709 测试总结](batches/0709测试总结/)分别有 14 批，每版 1271 组、1379 轮。同批编号在两版中对应同一批用例，可按需要选用其中一版。
- 精选测评有 100 题原版和联调日期适配版。联调版沿用同一套题，调整了部分日期。
- 专项测评包含计财业务 9 题、业务问数 30 题和 50 题、业务口语 20 题和 40 题，以及历史慢响应复测 20 轮。

文件里的人工期望用于复核。数据覆盖和业务结论以实际测评结果为准，原始用例的占位题仍需业务确认。
