# Ask Metric 平台功能清单：菜单、页面与操作

日期：2026-10-27。与[问数数据准备清单](问数数据准备清单-2026-10-27.md)配套：本文回答平台“哪里能做什么、按钮是否接通、还需要补什么”，数据清单回答“问好某类问题要准备什么数据”。

本轮只读核对 Vue 页面、路由、API 与执行调用，没有登录页面或调用模型/数据库。“已接线”指源码有实现，不表示已通过当前环境实测；“未发现”限于当前仓库。建议操作与现有操作分开列，未修改菜单、按钮或业务代码。

## 1. 当前菜单和角色

| 现有入口 | 路由 | 可进入的角色 | 当前职责 |
| --- | --- | --- | --- |
| 登录 | `/login` | 未登录用户 | 用户名密码登录；URL token 单点登录，不是独立 SSO 按钮 |
| 指标问数 | `/chat` | 登录用户 | 提问、历史会话、结果与诊断 |
| 指标术语 | `/metrics` | 登录用户可读；管理员可写 | 指标编号、名称、单位、说明、口径及同义词 |
| 机构别名 | `/orgs` | 登录用户可读；管理员可写 | 机构标准名与别名，不是完整组织权限树管理 |
| 数据集 | `/datasets` | 登录用户可读；管理员可写 | 数据资产登记；未完整参与运行时选源与字段映射 |
| 问数日志 | `/query-runs` | 登录用户；仅本人记录 | 查看问数记录及执行详情，管理员也不能直接跨用户看 |
| 智能配置 | `/llm` | 系统管理员 | 后端模型配置、提示词发布与历史 |
| 业务知识 | `/knowledge` | 系统管理员维护 | 标题/正文/启停；普通用户可在问数中检索启用知识 |

指标、机构、数据集页面的写按钮目前未按角色隐藏，普通用户能看见但后端会拒绝写入。这应补齐前端权限状态，不能误写成已经存在写权限越界。

## 2. 现有页面与按钮明细

### 2.1 登录及通用导航

| 操作 | 实际行为 | 当前边界 |
| --- | --- | --- |
| 登录 | 获取公钥后提交 `/api/v1/auth/login`，成功返回目标页面 | 用户名密码必填；无机构选择 |
| 显示密码 / 隐藏密码 | 本地切换输入显示 | 不修改密码 |
| 菜单项 / 品牌链接 | 切换页面 | 智能配置、业务知识受管理员菜单和路由限制 |
| 折叠 / 展开侧边栏 | 切换布局 | 刷新恢复默认展开 |
| 退出登录 | `/api/v1/auth/logout` 后回登录页 | 账号区显示机构/角色/范围；未发现资料编辑入口 |

未发现注册、忘记密码、修改密码、切换机构按钮；是否需要这些功能应先对照行内身份系统，不默认另做账号中心。

### 2.2 指标问数：会话与输入

| 操作/位置 | 实际行为 | 状态和限制 |
| --- | --- | --- |
| 新建对话 | 打开空草稿；首次发送才创建原生 session | 已接线，点击本身不调用模型 |
| 收起 / 展开历史对话 | 控制历史面板 | 与全局侧栏独立 |
| 点击历史会话 | 读取本人 session，运行中会话重新观察流 | 已接线；旧格式会话只读 |
| 会话 `…` → 修改名称 → 保存/取消 | 修改标题覆盖 | **仅 localStorage，非服务端持久改名**，跨设备不一致 |
| 会话 `…` → 删除会话 → 确认/取消 | `DELETE /agent-api/sessions/{id}` | 删除会话与消息；执行中受前后端限制；旧会话无此入口 |
| 示例问题 | 预填输入框 | 不自动发送；部分示例日期写死，需核对实际可用性 |
| `+` 添加指标或机构 | 切换指标/机构，搜索、点选插入文本 | 读取启用目录；不是增加指标或机构数据 |
| 选择器：继续输入 / 关闭搜索 / 重试 | 关闭选择或重读目录 | “重试”仅目录加载失败时出现，不是重跑回答 |
| 发送 / Enter | `/agent-api/sessions/{id}/prompt` | 1—1000 字，Shift+Enter 换行；旧会话/未就绪/正在运行时限制发送 |
| 停止生成 | 按 request/operation 发取消，停止本地观察 | 条件显示；必须区分取消确认和后台可能仍执行 |
| 用户消息：复制问题 | 复制该条原话 | 悬停或键盘聚焦可操作 |

当前未发现历史搜索、置顶、分组、批量删除、编辑后重发、通用“重新生成回答”按钮。澄清通过输入与目录选择完成，不能因组件名含 Clarification 就列出不存在的“提交澄清”按钮。

### 2.3 指标问数：回答、图表与明细

| 操作 | 实际行为 | 出现条件/限制 |
| --- | --- | --- |
| 复制回答 | 复制答案正文 | `ChatResultContent` 有可复制正文时；纯文本回退入口未见同样按钮 |
| 执行过程展开 / 收起 | 展示真实步骤摘要 | 有步骤时可展开；执行中默认展开、完成收起 |
| 执行耗时查询 / 收起 | 展示耗时与可用诊断 | 有后端 task_id 才能取得后端详情 |
| 调试 / 关闭调试面板 | 加载任务详情、SQL/轨迹等 | 当前无管理员前端限制；普通业务展示范围需收敛 |
| 后端任务下拉框 | 选择本轮某个后端任务 | 仅一轮多个任务时出现 |
| 表格 / 折线图 / 横向柱状图 / 柱状图 | 本地展示方式切换 | 数据适合时才显示；已有报告图表时不显示这组切换；无独立固定“饼图”按钮 |
| 查看 N 条数据明细 / 收起 | 显示本次已加载结果 | 有结果行时才出现 |
| 每页 10/20/50、上一页/下一页 | 已加载明细本地分页 | 超过10行显示；正常明细回填有数量上限，不能据分页推断全量下载 |
| 下载 Excel | `/api/v1/query-tasks/{id}/result-export` | **当前为大结果 download 分支，不是所有表格的通用按钮**；仍有归属和权限校验 |
| 切换为：某时间口径 | 原请求加时间覆盖重新查询 | 仅返回备选口径且最后一条已完成回答可操作；会执行实际查询 |
| 查看状态说明 / 分析思路 / 查看计算口径和数据来源 | 展开返回的说明 | 按结果类型与实际内容出现，不是常驻功能 |

未发现赞踩/纠错反馈、保存分析、授权分享、报告文件导出按钮。自然语言要求画图是问数能力，不能和一个前端图形切换按钮混为一项。

### 2.4 指标术语

| 操作 | 接入/作用 | 边界 |
| --- | --- | --- |
| 新增指标 | `POST /api/v1/catalog/metrics` | 管理员；只新增目录，不产生事实值 |
| 刷新 | 重读目录列表 | **不执行源目录同步** |
| 搜索指标 / 清空搜索指标 | 前端列表过滤 | 与后端运行时指标检索不是同一功能 |
| 显示已停用 | 切换列表可见项 | 不重新启用指标 |
| 编辑指标 | 打开当前条目表单 | 编号不可修改 |
| 保存指标 / 保存修改、取消 | 新增或 `PUT /metrics/{code}` | 保存时更新同义词集合 |
| 停用指标 / 启用指标 | 修改 enabled | 影响启用目录；源同步覆盖规则仍需明确 |
| 删除指标 → 确认删除 / 取消 | `DELETE /metrics/{code}` | **实际软停用，与停用重复；可用现有启用恢复** |
| 上一页 / 下一页 | 前端每页15条 | 不是运行时查询分页 |

表单字段：**指标编号、指标名称（必填），单位、同义词、指标说明、指标口径**。同义词逗号分隔、去空去重。当前无来源版本/责任人/关系审批/事实覆盖表单。

### 2.5 机构别名

| 操作 | 接入/作用 | 边界 |
| --- | --- | --- |
| 新增机构 | `POST /api/v1/catalog/organizations` | 管理员；不会自动创建机构事实或用户权限 |
| 刷新 | 重读机构列表 | 不同步源机构目录 |
| 搜索机构 / 清空搜索机构 | 前端列表过滤 | 可查名称/编码/别名 |
| 显示已停用 | 切换列表可见项 | 不修改实际状态 |
| 编辑机构、保存机构 / 保存修改、取消 | `PUT /organizations/{code}` | 编号不可修改 |
| 停用机构 / 启用机构 | 修改 enabled | 权限和正式层级仍由服务端及源资料决定 |
| 删除机构 → 确认删除 / 取消 | `DELETE /organizations/{code}` | 实际软停用 |
| 上一页 / 下一页 | 前端每页15条 | 已接线 |

表单字段：**机构编号、标准机构名（必填），别名**。当前不提供父机构、层级、有效期、账号授权编辑，不能称完整机构树管理。

### 2.6 数据集

| 操作 | 接入/作用 | 边界 |
| --- | --- | --- |
| 新增数据集 | `POST /api/v1/catalog/datasets` | 写登记表；未完成执行接入 |
| 刷新 | 重读登记列表 | 不扫描库表或测试连接 |
| 显示已停用 | 切换可见项 | 无搜索框 |
| 编辑、保存数据集 / 保存修改、取消 | `PUT /datasets/{id}` | 保存登记资料；**不代表查询已读取新来源** |
| 停用数据集 / 启用数据集 | 修改登记 enabled | 当前不能据此承诺已控制实际查询 |
| 删除 → 确认删除 / 取消 | `DELETE /datasets/{id}` | 实际软停用；弹窗标题“停用数据集”但确认仍为“确认删除” |
| 上一页 / 下一页 | 前端每页15条 | 已接线 |

表单只有**数据集名称、Schema、表名**，均必填；提交的类型/方言固定 mysql。当前无连接地址/账号/密钥/字段映射、读表结构、连接测试或查询预览按钮。后端具备其他数据库适配不等于该表单已经支持它。

前端保留无 id 时的“默认”只读分支，但当前列表 API 只读登记表，不能据该兼容分支写成“自动建立默认可查询数据集”。

### 2.7 业务知识

| 操作 | 接入/作用 | 边界 |
| --- | --- | --- |
| 新增知识 | `POST /api/v1/catalog/business-knowledge` | 系统管理员 |
| 刷新 | 重读知识与 revision | 不自动重建另一套语义索引 |
| 搜索业务知识 / 清空搜索 | 页面列表过滤 | 与模型端按需检索分开 |
| 显示已停用 | 查看停用条目 | 停用知识不供正常运行检索 |
| 编辑知识：标题 | 打开表单全文 | 管理员 |
| 保存知识 / 取消 | 新增或 `PUT /{id}` | 写配置 JSON，非知识数据库表 |
| 启用知识 / 停用知识：标题 | `PATCH /{id}/enabled` | 保留条目，修改运行可用状态 |
| 放弃本次修改并重新读取 | 冲突后重载最新内容 | revision 防覆盖，不等于历史发布版本 |
| 上一页 / 下一页 | 前端每页15条 | 已接线 |

表单为**标题、知识内容、启用这条知识**。标题最多200字，正文最多8000字。当前无删除、附件、导入、业务主题、来源链接、资料日期和历史版本控件；后端支持部分元数据并保留旧值，不代表页面可编辑。用户此前已选择精简表单，资料治理不自动等于把这些字段全加回来。

### 2.8 问数日志

| 操作 | 接入/作用 | 边界 |
| --- | --- | --- |
| 刷新 | `GET /api/v1/catalog/query-runs` | 仅本人记录，失败保留上次结果 |
| 查看完整问题 / 原始问题 / 机构匹配信息 / 错误详情 | 展开已有文本；机构全文按需取详情 | 按数据有无出现 |
| 详细流程：查看 / 关闭调试面板 | `/catalog/query-runs/{task_id}` | 展示执行详情，不会重跑 |
| 上一页 / 下一页 | 服务端分页，每页10条 | 当前页顶部统计，不是平台全量成功率 |

当前没有关键词搜索、日期/状态/机构筛选、重置、导出、删除或重新执行按钮；“重试”列是次数，不是重试操作。

### 2.9 智能配置

**全页：** Provider/Chat 模型/写入状态展示、刷新；按环境出现管理令牌输入和可写/只读提示。只有管理员可进入，保存还受服务端写开关及配置的管理令牌约束。

| 页面区域/操作 | 实际行为 | 生效边界 |
| --- | --- | --- |
| 模型配置 / 提示词配置 | 切换两个标签页 | 导航说明含“SQL”，但当前无 SQL 配置页/按钮 |
| Chat / 语义模型、Embedding 模型、Reranker 模型 → 启用 | 修改角色草稿开关 | 保存后更新后端配置 |
| 各模型 → 连接测试 | 用当前草稿和输入密钥调用对应后端测试接口 | **真实模型调用**；不保存草稿；禁用角色不可测试；非后台巡检 |
| 保存全部模型配置 | `PUT /api/v1/model-config/model` | 保存模型与新输入密钥；密钥空值保留旧值；当前无模型版本/回滚 UI |
| 提示词 → 选择节点 | 读取该节点字段、可编辑项、变量和历史 | 节点来自后端，不提供任意新增/删除节点 |
| 提示词 → 校验并发布 | `PUT /model-config/prompts/{name}` | 校验字段/模板约束并发布，不等于业务效果验证 |
| 提示词 → 版本记录 | 查看版本、操作、操作者和时间 | 发布/回滚历史已有 |
| 提示词 → 回滚 | `POST /prompts/{name}/versions/{id}/rollback` | 产生新的回滚记录；不是回滚 Agent 源码主提示词 |

表单字段按区域列明，均不表示已配置值：

- **模型共同字段：** Provider，Base URL、接口路径、模型名、发送 model、鉴权方式/请求头/前缀、密钥环境变量、超时、API Key、附加参数 JSON。
- **Chat 字段：** Temperature、Max tokens、响应格式及发送开关、深度思考/旧接口兼容开关、用户消息后缀。
- **Embedding 字段：** 向量维度、编码格式、User。
- **Reranker 字段：** 候选字段名、Top N、发送 top_n/return_documents 开关；无独立 return_documents 值控件。
- **提示词字段：** 由节点决定系统提示词、用户模板、检索前缀、查询模板及部分思考开关；核心只读约束有保护，不提供自由修改。

**必须分清生效路径：**

1. 此页主要维护后端模型/提示词，已有本地配置与配置中心适配。
2. inquiry 主模型来自 Agent 启动配置，主提示词在 `inquiry/runtime.ts`；页面保存不会同步修改这两项。
3. inquiry 的指标搜索会条件性调用后端 Embedding，因此不能说页面全部无效。
4. “指标向量召回”的 query_prefix、“指标候选重排”的 query_template 虽可发布，当前运行调用未发现读取；应核对真实消费路径后再说明效果。

## 3. 建议补齐的菜单/按钮：与现状分开

“先修”指使现有承诺真实且一致；“下一批”指可形成平台日常使用能力；“按需”只有明确业务场景才实施。下列都不是已完成或本轮授权开发。

| 菜单/区域 | 建议新增或调整操作 | 顺序 | 验收要求/数据依赖 |
| --- | --- | --- | --- |
| 指标/机构/数据集 | 按权限隐藏或禁用已有写按钮 | 先修 | 普通用户读取正常，写操作仍由服务端拒绝 |
| 数据集 | 明确登记与执行配置边界；查看当前生效来源；让保存/停用承诺与执行一致 | 先修 | 原始来源、字段映射、唯一配置权威明确；不是只改成功提示 |
| 指标/机构/数据集 | 合并删除与停用的重复语义、统一确认文案 | 先修 | 不新增硬删除，不破坏已存资料和历史 |
| 智能配置 | 标明作用组件、生效方式/时点、当前版本；收敛无消费字段的承诺 | 先修 | 不让后端页面被误当 Agent 主配置；不再建配置中心 |
| 指标问数 | 历史搜索、服务端修改名称、读取失败局部重试 | 下一批 | 不跨用户，跨设备一致，重读明细不重新调用模型 |
| 指标问数 | 普通结果下载 Excel、保存分析 | 下一批 | 所有获准结果可明确导出；保存统计期、来源版本；重跑形成新结果 |
| 指标问数 / 反馈管理（建议入口） | 提交纠错、选择原因、补充说明；处理人查看/处理/复测/转案例 | 下一批 | 消息归属检查；标准答案人工核实；反馈不直接变知识 |
| 指标术语 | 查看来源/覆盖；预览目录同步差异、执行同步、查看结果 | 下一批，平台管理员需要同步时 | 复用现有同步；定义本地覆盖/停用规则；同步不创造事实数值 |
| 机构别名 | 查看正式层级/范围；预览/执行机构同步 | 下一批，管理员维护时 | 只读展示正式层级优先；不通过别名编辑扩大权限 |
| 问数日志 | 搜索、日期/状态筛选、重置、复制任务编号 | 下一批 | 服务端分页一起过滤，保留本人范围；后台审计另按角色设计 |
| 业务知识 | 查看完整资料、来源/适用说明、变更记录；有需要时恢复版本 | 下一批，治理需求确定后 | 复用精简表单；来源可在管理详情/现有资料系统追溯，不强迫全部字段必填 |
| 评测管理（建议入口，可先文件报告） | 导入/维护样例、运行指定版本、查看差异、确认结论 | 下一批 | 复用已有脚本；真实样例、执行条件与独立答案依据，不能只评价流畅程度 |
| 数据接入（可扩展现有数据集） | 检查连接、读取结构、维护映射、查询预览、启停 | 按自助接入范围建设 | 先接通运行配置、权限和秘密引用；不是现有页多几个按钮就自动支持多库 |
| 我的分析 / 我的报告（建议入口） | 查找/查看已保存分析；选择模板、生成报告、取消、失败重试、下载 | 按业务产出，周期报告明确时前移 | 参考 MFWS 的任务/模板/归属与导出，使用 Ask 的真实数据与权限 |
| 管理详情/外部平台 | 用户/岗位权限、使用量/费用、告警/审计、发布恢复记录 | 推广门槛按现有平台落实 | 可对接 IAM/网关/APM/审计；不能因没有新菜单就默认未建设 |
| 分析资产 | 分享、接收人授权、有效期、订阅、阈值告警 | 按需 | 现有 BI/报表优先复用，明确接收者权限和失败处理 |
| 指标/机构/知识 | 批量导入导出、批量启停、文档附件 | 按需 | 数据量和实际维护频率决定；导入需预览、逐项错误、来源与权限 |

这些能力不要求一项一个一级菜单。先维持现有导航，细项可放进对应详情页/操作区；新增反馈、评测、报告入口时再根据角色和频率确定位置。

## 4. 平台功能与数据工作怎么对应

| 平台动作/目标 | 必须准备的数据 | 只做界面为何不够 |
| --- | --- | --- |
| 指标术语新增/编辑 | D01 指标字典与单位，D03 事实覆盖 | 有名称但无正式值，仍问不出来 |
| 机构别名和默认我行 | D02 标准机构、层级和账号授权 | 别名不等于组织范围和访问权 |
| 数据集保存/启用 | D03 数据源/粒度/映射、D09 质量和批次 | 登记不等于查询执行读取 |
| 同比环比/趋势 | D04 比较口径和历史，D03 真实值 | 没有正确基期，图表和文案不能补救 |
| 结构图/贡献归因 | D05 互斥完整关系、两期对账 | 有父子名称不代表可加总 |
| 贷款质量评价 | D06 正式口径与适用评价依据 | 模型常识不能替代本行阈值和分母 |
| 客户转出分析 | D07 授权明细和交易规则 | 聚合余额不包含资金去向 |
| 知识维护 | D08 本行方法/知识/事件资料 | 保存文本不等于召回适用资料，也不是实时事实 |
| 反馈/评测 | D10 原话、核准条件与独立答案依据 | 点赞/生成成功不能代表准确 |

字段解释、提供方清单及具体问法见[数据准备清单](问数数据准备清单-2026-10-27.md)。平台工作和数据整理可以并行；必须在同一场景上共同验收。
