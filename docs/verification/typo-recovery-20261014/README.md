## 行为与边界

- 精准名称仍走原识别路径。完整基础指标的一字差异只有满足全目录竞争优势、正式身份唯一和明确口径时自动纠正；分数是相似度阈值，不是概率。短词、缺口径、竞争候选、语义限定变化等继续确认。保留原文跨度、正式编码与纠错依据。
- 可信候选确认独立保存。恢复回执提供剩余提案的依据及是否可明确继承旧值；有本轮依据的真实修改和数量约束不能被省略、继承或旧快照吞掉。失效点选不回退为其它字段的文字同意。
- 排名方向、条数须有本轮原文或可信历史依据；缺项保存后澄清，不补前 10 名。省略、继承和清除同样校验。越界数量、否定旧榜单、机构数量与指标名称中的“排名”均有回归覆盖。
- 保留重复失败停止保护。修复造成循环的确认状态与恢复回执不一致，不能承诺未经真实模型验收的任意措辞都能一次处理。

完整契约见[历史字段引用、确认与恢复](../../business-context-reference-recovery.md)。
