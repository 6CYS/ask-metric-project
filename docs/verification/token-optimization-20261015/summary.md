## 准确性、恢复与权限

- 用独立固定 spec 取得参考结果，合并后端前置的 7 个参考查询全部与旧冻结值 hash 相等。逐回合检查正式机构、指标、日期的分别绑定，Decimal 值、NULL、单位、排序、完整行数、非截断以及所需目标全部完成。真实样本没有覆盖的 NULL/零值和大结果边界由隔离回归覆盖，不冒充开发库实测。
- 每个回合比较旧 Frame hash，关闭后重新打开会话并 GET 恢复，正文与结构结果一致；分别计量并断言恢复阶段模型请求增量、usage 增量、业务取数提交增量均为零。若恢复意外新增模型调用，用量也会纳入同一回合账本。
- 缺项追问曾出现目录旁支冒充完成及 `source:new` 丢历史字段，均有真实失败 trace，修复后 final-4 三次重复全部通过。宿主要求 Pi 显式使用签发来源重提，不默默继承或改旧计划。
- 真实环境验证当前合法鉴权、结果来源和会话归属。撤权、多结果中一项失权、跨用户嵌套引用负例由隔离测试覆盖；未修改真实账号权限，未宣称真实撤权测试。
- 整笔计算只产生 1 次正式 calculation、1 个结果；精确六月减五月、元单位、正文全部金额的万元换算/显示舍入、日期/差额标签、精确元差额和变化方向均逐项核对通过。基线解释修复两次、候选 `CALCULATION_REQUIRED` 一次均保留，见 `final-4-calculation-review.json`。
