## 准确性与失败场景证据

独立基准通过项目正式查询规划器和只读数据适配器执行2次查询，得到3家机构、2个指标、2个日期的12个数据点。基准与模型答复分开取得，比较机构编码、指标编码、日期及 Decimal 原值；多结果还检查行数、重复与截断，排名检查完整范围及顺序，计算检查原任务身份、输入原值和公式方向。基准文件哈希为 d0ad210a663adeddeb4d8c28216aef0e16d303458468a0c750aa18e84abf8c30。

| 验证内容 | 实际结果 |

| 多目标日期绑定 | 无锡六月、江阴五月互换正确，没有仅校验日期并集 |

百轮夹具的105轮没有调用外部模型，业务账本哈希在填充与压缩前后相同。它验证长历史后的定位与恢复；真实模型部分为早期2次查询及压缩后跨历史请求，未将105轮合成填充计入真实问数正确率。

撤权通过隔离开发进程内权限策略执行，使用真实登录身份与开发数据库。测试中发现并修正了目录过滤夹具的误拒绝；还发现权限过滤后旧机构身份消失，导致先读另一有权结果再被交付门禁拦截。最终代码使用原签发范围识别旧身份，并在读取工具入口独立检查当前权限，失权用例不再读取替代结果。
