## 环境及证据边界

当前正常配置为 development / MySQL；应用库和查询源指向同一个 loopback 端点及 schema。实际服务器响应为 MySQL 8.0.45，运行时查询的 `metric_values` 是物理 BASE TABLE，并非指向数据湖的视图。不能仅凭库名、目录编码、现存数值或本地连接证明其上游湖来源和新鲜度。

Excel 对应的 97,540 条事实中，24,212 条的来源批次含严格词边界匹配的 synthetic / fixture / mock / demo / seed / seeded / test 标记；另 73,328 条来源未证实。严格规则不会把 latest 误匹配为 test。因此，本轮数据应称为“含测试来源标记的本地运行库”，不能冒充纯真实数据湖验收。
