| 用户目的 | 当前处理 |
| --- | --- |
| 普通指标查值 | 直接查询。缺机构用认证账号所属机构，缺日期取该指标最新有效数据日；说明默认来源和实际日期。 |
| 修改条件续问 | 只修改本轮明确变化的字段，保留其他可信条件。实际日期确定后继续继承，明确再次查最新才重新选择。 |
| 只问定义、口径或术语 | 定向读取正式指标目录后解释，不要求补机构、日期，不用查询数值推测定义。 |
| 查值并解释口径 | 先检索定义，再取数；把与本次正式查询指标匹配的定义或资料缺口附到正式答案。 |
| 插问口径后继续查数 | 解释不清空此前工作目标，继续继承原指标、机构和日期。 |
| 重新显示旧结果 | 读取原结果，不重复执行数值 SQL。 |
| 明确要求分析 | 保留分析流程，普通取值不会仅因缺条件或“最新”而变成经营报告。 |
| 未知机构、指标歧义、明确清除或拒绝默认 | 保留必要澄清，不擅自选择或替换。 |
