name: metric-query
description: 经营指标的名称、机构范围、日期粒度、条件继承与澄清口径，以及历史结果的业务含义。
---

正式目录中的指标名称是完整业务概念。名称里的“增幅”“较同期”“排名”可能属于指标本身，不应擅自拆成公式；多个指标逐项保留。名称映射以正式目录解析结果为准，已确定的映射可直接使用；未知、停用或仍有歧义的名称需要核对，不能自行改用其他指标。

指标、机构、时间和取值口径共同定义一次查询。缺少条件与没有数据是不同状态；目录中存在指标，也不证明目标机构和日期有记录。机构别名以正式目录为准，“各家农商行”“全省各行”等表示集合范围，不是某家机构的名称。结果范围始终受当前用户权限限制。“各家农商行”只包含正式层级中账号可见的同级农商行，不混入省级汇总和下属支行；某行下属支行是另一种明确范围。

独立问题依据本轮明确条件；追问继承有依据且未被修改的条件，本轮明确修改优先。仅换机构时保留日期和指标，随后改日期仍沿用最新已确认的机构。失败的修改不代表新条件已经生效，也不能悄悄退回更早结果。多个来源均合理时，需要核对用户指代。

数据覆盖记录里的机构和完整日期范围可作为追问依据。用户从覆盖列表选指标或修改机构时，其他明确沿用的条件应保留；分页样例不是完整范围。覆盖记录与取值结果是不同证据，覆盖记录不代表已完成数值查询。

澄清只补充实际缺失或有歧义的条件，保留已有指标、机构和时间。用户补充的内容必须进入正式任务，只有任务回执能证明条件已更新；不能凭对话文字声称已补充、已确认或又缺少某字段。新独立问题不因之前存在待澄清任务而被强行合并。

“3月末”“3月份”“3月份每日明细”可能对应不同时间粒度。余额通常是时点存量，不能把每日余额相加作为月度余额。用户明确要求整月全部记录时，应覆盖完整区间；时点、日均或整月序列存在歧义时只澄清相关口径，不要求重述已确认的其他条件。

日期条件与排名操作相互独立：指定某一天或月末按精确日取数（exact），仍可按该日数值排名；只有在多日范围内寻找最后有数据日时才用 latest_in_range。前3名通常表示数值降序最多3家，同值按稳定机构次序；不自动扩大范围或倒退日期。换月份保留已明确排名，取消排名后普通列出全部目标。整月每日排名尚不支持时如实说明，不能只取一天冒充。

历史重显是展示已经取得的结果；改变机构、指标、日期或粒度意味着新的取数目标。历史值保留其原日期和来源，不冒充当前查询结果。零行成功结果同样属于可回看的正式历史。

结果须对应用户目标的全部条件；缺数、截断、失败和未完成部分应清楚说明。数值、单位和展示口径以权威回执为准，指标排名单位为“名”时不等同于按某个数值重新排序。
