## 适用任务

用于判断经营指标的具体取值、排名、条件追问和历史重显。覆盖发现只说明记录范围；自定义运算还需要正式计算结果。参数结构与合法组合以工具 Schema 和回执为准，查阅本知识不是执行前置步骤。

## 业务判断

先区分本轮目的。只问指标定义、口径、术语或口径区别时，检索正式目录的指标说明和口径后解释，不补机构、日期，不执行数值查询来推测定义。本知识只提供查询方法，不能代替具体指标定义；已读的同版本正文直接复用。正式定义为空时说明缺失内容，不用名称、别名或常识补造。用户同时要求取数和解释时分别完成；中途询问口径不清除原查询条件，之后的续问仍只修改用户明确变化的部分。

正式目录中的指标名称是完整业务概念，名称里的“增幅”“较同期”“排名”可能属于指标本身，不擅自拆成公式；多个指标逐项保留。映射以正式目录解析结果为准，已确定映射可直接使用；未知、停用或仍有歧义时核对，不改用其他指标。用户只说基础指标时，由系统候选请用户选择统计口径，不默认当日数或某种增幅。同一基础指标下的多个口径确认一次即全部确定；回执注明“按某指标理解”时在回答中说明。

指标、机构、时间和取值口径共同定义查询。缺少条件与没有数据是不同状态；指标在目录中不证明目标机构和日期有记录。机构别名由正式目录确定，机构集合与具体名称是不同输入；集合、同级和下辖范围均由服务端按正式层级及当前权限确定。全省各行或各家农商行的同级范围不混入省级汇总和下属支行，也不能把未知名称改成集合来扩大范围。

结合本会话历史索引理解指代，声明所引用的来源字段及组合关系，不展开历史名称或生成编码。服务端核对来源所属会话、状态、权限和用户明确的数量。来源唯一时，不因缺少数量词而追问；有多个合理来源或数量不符时保留条件并澄清，不按最近若干条记录猜选对象。

条件优先级是本轮明确条件、可信续问继承、真正新问题的缺省默认。普通取值的新问题缺机构时，由宿主核验认证账号所属机构；缺日期或无明确期间的“最新/最近/近期”，由服务端按该机构与指标取最新有效数据日。模型只提交已知字段，不编机构编码、不假定全省或今天。回答保留默认来源和实际日期，用户可更正。指标未知、候选歧义、失败、明确清除或拒绝的条件不按缺省处理。追问继承有依据且未修改的条件，本轮修改优先。查询成功且结果统一到一个实际数据日后，仅换机构或指标继续保留该日，明确再次查最新才重选。上次结果为空或各项日期不同时，不能伪造统一时点；用户明确要求日期不变时需澄清，明确查最新或继续沿用最新策略时可重新取数并披露日期。随后改日期沿用最新已确认机构。继承整笔业务与只引用其中一个字段是不同操作，按用户目标选择来源。失败修改不代表新条件已生效，也不能悄悄退回更早结果。新独立问题不因旧待澄清任务而被强行合并。

数据覆盖记录中的机构和完整日期范围可作为追问依据。从覆盖列表选择指标或修改机构时，保留明确沿用的其他条件；分页样例不是完整范围，覆盖记录也不代表已完成数值查询。

月末、整月和每日明细对应不同时间粒度。余额通常是时点存量，不能把每日余额相加作为月度余额；整月全部记录保留完整区间。明确单日按指定日取值（exact），仍可按该日排名；连续范围内寻找最后有数据日才使用 latest_in_range，不把整月自行改成月末或倒退日期。

日期取数方式与查询目标独立。取值、榜单和对象位次使用不同契约：榜单需要前后方向与条数；位次需要关注对象和比较总体，不需要榜单条数。比较总体人数不等于返回条数。关注对象可以只有一个，排名仍须基于已确定的完整比较总体计算，再显示关注对象；不能先把总体过滤为关注对象。范围由正式目录、层级和当前权限核验，没有合法且唯一的依据时只澄清比较范围，不默认为全部机构。

实际升降序由服务端按指标决定；单位为“名”的指标数字越小越靠前，不自行换算方向。同值沿用稳定排序规则，不扩大范围。结果区分请求比较总体、同一取数时点的有效样本与缺数，不将实际样本量冒充完整总体。换期间保留已明确目标及范围，取消排名后按新的取值目标执行。尚未支持的每日排名如实说明，不只取一天冒充完成。

## 澄清与恢复

只补充真正缺失或有歧义的业务选择，保留已知指标、机构和时间。用户已明确日期口径、排名方向或条数而模型漏参时，应依据原文或可信继承修正参数；无法唯一确定时，使用 Schema 声明的结构化澄清保存条件，除上述宿主缺省政策外不猜业务选择，也不向用户索要技术字段。

确认依托系统已保存的候选及本轮回复。候选由系统编号展示并确定所选项，不自行罗列或挑选；理解同意时保留完整否定和转折语义。单候选已有明确同意可确认；多候选须有明确选择；没有已存候选的同意不能凭空建立确认状态。只确认一个字段时，其余已知条件继承、未决候选继续保留。服务端保存的点选进度与恢复闸门以最新回执为准；同句修改其它条件须一起处理完成才能执行，不因局部确认完成就提前查询。

对照判断：历史来源唯一但没有数量词，可以继续；存在多个合理来源，才核对所指对象。用户已给选择但参数不完整，修正调用；用户未给必要选择，保存并提问。依据具体语义判断，不把这些例子当作关键词规则。

## 证据与完成

只有正式任务回执能证明条件已更新或确认，不能凭对话文字声称已补充、已确认或再次缺项。历史重显展示已取得结果；改变机构、指标、日期或粒度是新的取数目标。历史值保留原日期和来源，零行成功结果也可正式回看。

结果须对应用户目标的全部条件。缺数、截断、失败和未完成部分清楚说明；数值、单位和展示口径以权威回执为准。正式排名指标的“名”不等同于对其他数值重新排序。普通查值直接回答结果，不因默认条件扩写经营报告。明确历史日期查无数据时保留原日期，不自动改查最新。
