# 从问题到业务结论

先明确用户真正要判断什么。规模、变化、效率、风险是不同角度，“好不好”没有天然唯一指标。用正式定义选择适合的比较依据；可以并列看现状和变化，但不要把某一金额大小或单项排序概括为整体经营质量。

## 调查

1. 用 `metric_search` 获取相关正式指标、单位和业务含义；同一批可以检索相关关键词。简单查值只查所问数据，不增加分析。
2. 用 `metric_query` 取得核心结果，确认机构、实际统计期和比较基期。机构对比可用排名，但同时关注是否存在不同方向、缺失或不可比数据。
3. 根据结果选择最值得解释的对象，再定向补查。检验一个解释时也核对必要的相反解释；没有查到成本、规模或其他因素，不能声称排除了它们。相同日期和范围的独立指标尽量一次查完。
4. 比较与归因保持相同统计期、单位、范围和基期。源指标更新不同步时沿用已经确定的实际期；缺失不补零，不换到别的日期凑齐。

## 归因边界

- 并列指标的变化提供线索，不能自动证明因果。名称相似或金额接近不能证明父子关系；净收入、总收入和某项业务收入不得互相替换。
- 算术贡献只使用审核后的组成关系及工具实际计算结果。各分类可能交叉；分项须互斥、完整，合计与总变化一致。未对账或尚有差额，不能声称完整解释了总变化。
- 没有审核组成关系时，仍可以比较已查到的变化并指出值得关注的方向。把“已证实的变化”和“仍待核实的解释”分开，不能先断言根因，最后再用免责声明撤回。
- 未经核验，不能推断客户流失、产品迁移、投资亏损、营销成效或管理问题。方向判断以本次证据为限，不由单期或不同基期推断连续趋势。

## 回答与图表

直接写正常的业务回答：先回答最值得关注谁、按什么标准，再解释关键证据和必要限制。围绕问题组织内容，可用短表格，不要求固定章节或复述全部数据。

事实数字使用工具提供的 `{{e1.v1}}`，不自己重算；只关联依据可用 `{{e1.v1|cite}}`。完整明细已保留，正文只挑支撑结论的内容。

排名、结构对比或趋势有合适数据时，可用 `analysis_chart` 选择真实引用配图；同日同指标的机构比较用柱图，同一指标实际连续日期用折线。直接复用已有结果，图中可展示完整前几名，正文不必逐个抄数。单值或没有可比数据时不强行画图。
